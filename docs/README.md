# Local documentation

This directory is deliberately usable without an internet connection after
`just docs`.

- `zig/language-reference-0.16.0.html` — self-contained Zig 0.16.0 language reference
- `libdragon/wiki/` — libdragon tutorials, installation notes, and troubleshooting
- `libdragon/headers/` — the complete Doxygen-commented public API headers
- `summercart64/protocol/` — official quick start, USB protocol, memory map, and firmware docs
- `m64/README.md` — concise console setup and compatibility notes
- `architecture.md` — how Zig and libdragon are joined in this project

The checked-in revisions are recorded in each upstream documentation folder.
The docs were refreshed on 2026-08-22. Source links remain below for checking
material that may have changed since the snapshot:
