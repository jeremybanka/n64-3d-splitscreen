# Original sample audio

`meadow.wav` is an original eight-second, 120 BPM melody and bass loop.
`hop.wav` is an original 180 ms rising chirp. Both are mono, 16-bit PCM at
22,050 Hz, generated by `scripts/make-audio.py` using only Python's standard
library. They contain no external samples, recordings or borrowed melodies.

These two recordings and their generated musical content are dedicated to the
public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
They may be replaced or reused freely in game forks.

Normal builds convert these checked-in sources to streamed VADPCM WAV64 with
the pinned SDK's `audioconv64`. Run `make audio-assets` to regenerate the WAV
sources explicitly, or `python3 scripts/make-audio.py --check` to verify them.
See [the playback and event interface](../../docs/audio.md).
